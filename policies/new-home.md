# New Home Tab (redesigned Home, default Nov 5 2026)

# Summary

As of **Thursday, Nov 5, 2026, 12:00 pm ET**, the redesigned Home tab is the default for **every app user**, including Apple and other organization members. Nothing was removed — the layout changed and a few things were added (Daily Dose for everyone, Playlists, a For you section). ## Standard Case — "where did X go?" / feedback on the new Home

1. Acknowledge the change warmly. Nothing was removed; the new Home arranges things differently and adds Daily Dose, Playlists, and For you.
2. Answer the specific "where is X?" using the FAQ / tour below.
3. Invite what they'd like changed; their note goes to the team.
4. Tag `new-home` (and `playlists` if needed). Append a CSV row. Capture what they couldn't find. Note if they switched back.
5. Reply with a **specific** thank-you that addresses what they said (never a generic thanks). Answer any where-is-X / switch-back ask in the same reply.
6. Sign-off: **Take care,** / **Happier Meditation Support Team**. Never Cass/Cassidy/first name. Never "Best wishes".

## If they want the old Home

Encourage them to give the new Home a try, but help them switch if they ask. Ask what they're missing and pass that feedback on.

**Steps to share:**

Home → Profile (person icon, top left) → Settings (gear, top right) → Manage → turn off **New Home**

**Suggested reply:**

> Sorry the new Home isn't working for you yet. You can switch back for now: tap the person icon at the top left of Home, then the Settings gear, and under Manage turn off New Home. We'd love to know what you'd like to see changed. Your note goes straight to the team.

- To return to the new Home, they turn the same **New Home** switch on again.
- The change takes effect the next time Home loads. If it doesn't, closing and reopening the app fixes it.
- **Do not promise** they can keep the old Home forever or name a date. Say the switch is available for a limited time while we collect feedback, and we're using notes like theirs to improve the new Home.

## Show weekly progress (without switching layouts)

On the same Settings → Manage screen as **New Home**, **Show weekly progress** hides the **This Week** card on the new Home **without** switching layouts. Offer this when they only dislike the progress / streaks card.

## Broken Home (blank Home, missing sections, can't play)

1. Ask them to **close and reopen** the app and make sure it's **up to date**.
2. If it persists, collect **email, device, app version, and a screenshot**, then escalate to the product team in **`#product-engineering`**.
3. Still tag `new-home` and capture symptoms.

## Tour of the new Home (top to bottom)

Some sections only appear when they apply (e.g. a challenge they joined or a course in progress), so two people's Homes won't look identical. Bottom tab bar is unchanged: Home, Courses, Singles, Sleep, Shorts.

1. **Top bar** — Profile (person icon, left), greeting, Search (magnifying glass, right). Settings, History, Downloads, Milestones, and Playlists are reached through Profile.
2. **Daily Dose and featured slides** — Large swipeable card at the top. Daily Dose is one hand-picked practice the whole Happier community gets each day; tap Play now. Other slides can feature something picked for the person, a new course or sleep story, or an open challenge.
3. **Check-in** — Monthly check-in still on Home; when due, a short prompt near the top.
4. **For you** *(new)* — Short list for that person: challenge ("Upcoming challenge" / "Your challenge"), Recommended, Try tonight, Dive back in (course in progress). **See all** under For you opens the full recommendations list (the old Home's short suggested-meditations list still lives there).
5. **Playlists** *(new)* — Their playlists, with See all.
6. **Challenges** — Open challenge to join, plus My Challenges. See all lists every challenge.
7. **This Week** — Weekly progress and streaks. Hide via Settings → Manage → Show weekly progress.
8. **My Circle** — Friends they practice with; invite a friend.
9. **Courses for you** — Suggested courses; See all for the full catalog.
10. **Your teachers** — Browse teachers.
11. **Browse by topic** — Topics like stress, anxiety, sleep.
12. **Sleep** — Sleep meditations, with See all.

## Playlists

- **Make one:** ⋯ menu on any meditation, sleep meditation, or course session → Add to playlist (can create a new playlist there).
- **Find them:** Playlists section on Home, or Profile → Playlists.
- **Play:** Open a playlist → Play (runs in order).
- **Share:** Playlist's ⋯ menu → share link with a friend.

## Logging feedback (Cassidy process — Nov 5 2026)

**Every Home or Playlists feedback ticket** (launch-email replies, in-app welcome feedback, "I don't like the new Home," Playlists comments, where-did-X-go that includes opinion/feedback, switch-back requests with reasons) must do all three:

### 1. Append a row to the feedback CSV

Path (on the support box Bert uses): `/home/box/happier-support/data/new-home-feedback.csv`

The file already exists with a header only. **Append one row per ticket** (do not overwrite the header or other rows). Columns, in order:

| Column | What to put |
|---|---|
| `ticket_number` | Help Scout conversation number |
| `conversation_id` | Help Scout conversation id |
| `received_at_et` | When the customer message arrived, America/New_York, e.g. `2026-11-05 2:15pm ET` |
| `customer_name` | Customer display name |
| `customer_email` | Customer email on the ticket |
| `topic` | Short topic label, e.g. `switch-back`, `playlists`, `daily-dose`, `where-course`, `where-challenge`, `this-week`, `broken-home`, `general-feedback` |
| `switched_back` | `yes` / `no` / `unknown` / `offered-not-yet` |
| `summary` | One-line paraphrase of their feedback |
| `verbatim_excerpt` | Short quote of their words (escape commas/quotes for CSV) |
| `what_they_couldnt_find` | Specific missing thing, or empty if pure opinion |
| `reply_sent_at_et` | When our reply went out (America/New_York), or empty if not yet sent |
| `hs_url` | `https://secure.helpscout.net/conversation/<conversation_id>/<ticket_number>` |

CSV hygiene: quote fields that contain commas or quotes; never delete prior rows; one ticket → one row (update the same row if you learn more later, rather than duplicating).

### 2. Tag the ticket

- Always tag **`new-home`**.
- Also tag **`playlists`** when the feedback is about Playlists (creating, finding, sharing, or the Playlists section/email).

### 3. Reply with a specific thank-you

- Thank them for the **specific** thing they said (name the layout bit, missing item, or Playlists detail they mentioned).
- **Never** send a generic "Thanks for the feedback!" with no substance.
- If they asked where something went or how to switch back, answer that in the same reply (see FAQ / switch steps above).
- Invite anything else they'd like changed; note it goes to the team for the Nov 30 decision.
- Sign-off: **Take care,** / **Happier Meditation Support Team**.

Launch-email replies are feedback for the Nov 30 decision — same three steps.

- **Ticket mixes Home feedback with billing/cancel/refund:** Handle the Home portion per this policy (tag `new-home`); handle billing per the relevant billing policy. Do not drop either ask.
- **Known bug that only looks like a Home layout question:** Cross-check `known-bugs.md` (e.g. check-in Home prompt, Daily Recommended refresh) and use that entry's customer script when it matches.
